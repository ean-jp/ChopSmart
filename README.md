# ChopSmart

**Eat Smart. Spend Smart.**

ChopSmart is a website project built with HTML, CSS, and JavaScript.

## Pages

- Home
- Vendors
- Menu
- Menu Builder
- Cart
- Orders

## Run locally

Open index.html in a web browser, or open the project in VS Code and use Live Server.

## Project structure

- css/ - stylesheets
- js/ - JavaScript files
- images/ - website images
- Root HTML files - website pages
